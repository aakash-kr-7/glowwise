## Gate rules

- **G1 Preparation:** T01 complete; future-stage actions not executed merely because this plan lists them.
- **G2 Spend:** T02 must pass immediately before creation. Estimates include credit-funded consumption, all recurring/retained resources, uncertainty and buffer. A listed free-service meter or historical picker price is insufficient. No infinite-hosting promise within US$10.
- **G3 Infrastructure:** T03–T05 pass through real SSH, health, DNS/TLS and persistence checks. A functioning protected WordPress installation is infrastructure, not a complete Glowwise release.
- **G4 Product:** T06–T11 satisfy the traceability rows. Seven initial guides are the working target from the existing map; ≥6 across six categories is the approved minimum. Expansion to 18–24 remains separate work.
- **G5 Launch:** T13–T15 pass; any material security, core journey, false content or privacy failure blocks launch. Optional inaccessible measurement tools are recorded with alternatives and limits.
- **G6 Assessment:** T16–T18 distinguish actual implementation from human demonstration, instructor marking, indexing and timely submission. No marks are self-awarded.
